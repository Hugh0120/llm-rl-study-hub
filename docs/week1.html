0.1 贯穿全文的例子：让模型学习做乘法题

假设训练样本给出 prompt：

计算 17 × 23，并给出简短推理。

当前模型可能采样出两条回答：

rollout 回答 verifier reward
A 17 × 23 = 391 111
B 17 × 23 = 381 000

训练目标不是把 1 或 0 当作 token 标签，而是：

  1. 让模型自己生成回答；
  2. 用 verifier 给整条回答打分；
  3. 判断回答中每个 token 相对“正常发挥”是好还是坏；
  4. 提高好决策的概率、降低坏决策的概率；
  5. 限制一次更新的幅度，避免模型为了这批题破坏原有语言能力。

后文所有公式都会回到这个例子。看见抽象符号时，可以立即替换：

状态 s_t       = “题目 + 当前已写出的答案前缀”
动作 a_t       = 下一个 token
轨迹 τ         = 一整条回答
策略 π_θ       = 当前语言模型
reward R(τ)    = verifier 对整条回答的评分

第一章：先把 LLM 后训练写成一个 MDP

本章问题：模型生成的是离散 token，为什么仍然可以把它当作一个可优化的决策过程？

强化学习不是“有 reward 的监督学习”。关键差异是：当前动作会影响未来会看见什么状态，也会影响未来能拿到的 reward。

先把下面的式子当作一张“组成清单”，不是要计算的等式。我们用 M\mathcal MM 给整个决策问题命名；花体字母 S\mathcal SS 和 A\mathcal AA 分别表示所有可能状态组成的集合、所有可能动作组成的集合。其余四项依次描述环境怎样变化、怎样给奖励、从哪里开始，以及怎样折扣未来奖励：

M=(S,A,P,r,ρ0,γ)\mathcal M=(\mathcal S,\mathcal A, P, r, \rho_0, \gamma)M=(S,A,P,r,ρ0​,γ)
  • S\mathcal SS：状态集合；sts_tst​ 是其中在时刻 ttt 真实出现的一个状态；
  • A\mathcal AA：动作集合；ata_tat​ 是策略在该状态真实选择的一个动作；
  • P(st+1∣st,at)P(s_{t+1}\mid s_t,a_t)P(st+1​∣st​,at​)：环境转移；
  • rt=r(st,at)r_t=r(s_t,a_t)rt​=r(st​,at​)：即时奖励；
  • ρ0\rho_0ρ0​：初始状态分布；
  • γ∈(0,1]\gamma\in(0,1]γ∈(0,1]：折扣系数。

一个容易忽略的点

环境转移对 LLM 通常不是难点：生成 a_t 之后，下一个状态就是把它拼到上下文里。但策略会改变训练数据本身：模型更新后，会采到不同的 token、不同的推理路径和不同长度的回答。这正是 RL 比监督微调难的根源。

1.2 轨迹分布与优化目标

先定义公式里的每个对象：

  • pθ(τ)p_\theta(\tau)pθ​(τ)：当前模型产生整条轨迹 τ\tauτ 的概率；下标 θ\thetaθ 提醒我们，模型参数一变，这个概率也会变；
  • ρ0(s1)\rho_0(s_1)ρ0​(s1​)：从题目或 prompt 分布中抽到初始状态 s1s_1s1​ 的概率；

对数学题 verifier，常见 RRR 是最终答案正确时的 111，否则 000。对 RLHF，RRR 往往来自 reward model。注意：即使奖励只在最后给出，每一个生成 token 都参与决定了该最终奖励。

为什么不是直接把 reward 当 label？

监督学习有固定 (x,y)(x,y)(x,y)；RL 的 yyy 来自当前 πθ\pi_\thetaπθ​。你真正要调整的是“采到这条回答的概率”，而不是把一个标量 reward 伪装成 token 标签。

第一章小结：我们有目标，但还没有梯度

到这里已经完成三件事：

  1. 把回答前缀定义为状态、下一个 token 定义为动作；

第二章：REINFORCE —— 让高回报轨迹更可能出现

本章问题：不能对采样出来的 token 求导，怎样把 reward 变成模型参数的梯度？

2.1 关键技巧：log-derivative trick

目标是调整模型参数 θ\thetaθ，让高回报轨迹更容易被采到。困难在于 τ\tauτ 是离散采样结果，不能把 token id 对 θ\thetaθ 直接求导。解决办法不是“对 token 求导”，而是对产生该 token 的概率求导。

下面从目标函数逐行推导。为便于阅读，先把轨迹看成离散变量；连续情形只是把求和换成积分。

第一步：把期望写成“所有轨迹的概率加权和”

J(θ)=Eτ∼pθ[R(τ)]=∑τpθ(τ)R(τ).J(\theta) =\mathbb E_{\tau\sim p_\theta}[R(\tau)] =\sum_\tau p_\theta(\tau)R(\tau).J(θ)=Eτ∼pθ​​[R(τ)]=τ∑​pθ​(τ)R(τ).

这里假设一次策略更新期间 reward 函数是固定的，因此 R(τ)R(\tau)R(τ) 不直接依赖 θ\thetaθ。对 θ\thetaθ 求导：

∇θJ(θ)=∑τR(τ)∇θpθ(τ).\nabla_\theta J(\theta) =\sum_\tau R(\tau)\nabla_\theta p_\theta(\tau).∇θ​J(θ)=τ∑​R(τ)∇θ​pθ​(τ).

到这里的问题是：我们想用采样估计这个梯度，但式子里只有 ∇θpθ(τ)\nabla_\theta p_\theta(\tau)∇θ​pθ​(τ)，还没有概率权重 pθ(τ)p_\theta(\tau)pθ​(τ)。

第二步：由链式法则得到 log-derivative trick

对任意正概率 pθ(τ)>0p_\theta(\tau)>0pθ​(τ)>0：

∇θlog⁡pθ(τ)=1pθ(τ)∇θpθ(τ).\nabla_\theta\log p_\theta(\tau) =\frac{1}{p_\theta(\tau)}\nabla_\theta p_\theta(\tau).∇θ​logpθ​(τ)=pθ​(τ)1​∇θ​pθ​(τ).

两边乘以 pθ(τ)p_\theta(\tau)pθ​(τ)，得到：

∇θpθ(τ)=pθ(τ)∇θlog⁡pθ(τ).\nabla_\theta p_\theta(\tau) =p_\theta(\tau)\nabla_\theta\log p_\theta(\tau).∇θ​pθ​(τ)=pθ​(τ)∇θ​logpθ​(τ).

这不是一个额外假设，只是 ∇log⁡p=(1/p)∇p\nabla\log p=(1/p)\nabla p∇logp=(1/p)∇p 的移项。将它代回上一步：

∇θJ(θ)=∑τpθ(τ)R(τ)∇θlog⁡pθ(τ)=Eτ∼pθ[R(τ)∇θlog⁡pθ(τ)].\begin{aligned} \nabla_\theta J(\theta) &=\sum_\tau p_\theta(\tau)R(\tau) \nabla_\theta\log p_\theta(\tau)\\ &=\mathbb E_{\tau\sim p_\theta} \left[R(\tau)\nabla_\theta\log p_\theta(\tau)\right]. \end{aligned}∇θ​J(θ)​=τ∑​pθ​(τ)R(τ)∇θ​logpθ​(τ)=Eτ∼pθ​​[R(τ)∇θ​logpθ​(τ)].​

现在式子重新变成了一个期望，所以可以用模型实际采出的 rollout 做 Monte Carlo 估计。

第三步：把“整条轨迹的 log 概率”拆成每一步

由第一章的轨迹分解：

log⁡pθ(τ)=log⁡ρ0(s1)+∑t=1T[log⁡πθ(at∣st)+log⁡P(st+1∣st,at)].\begin{aligned} \log p_\theta(\tau) &=\log\rho_0(s_1)\\ &\quad+\sum_{t=1}^{T} \left[ \log\pi_\theta(a_t\mid s_t) +\log P(s_{t+1}\mid s_t,a_t) \right]. \end{aligned}logpθ​(τ)​=logρ0​(s1​)+t=1∑T​[logπθ​(at​∣st​)+logP(st+1​∣st​,at​)].​

对 θ\thetaθ 求导时：

  • ρ0\rho_0ρ0​ 是数据或 prompt 的来源，不由模型参数控制，所以梯度为 000；
  • PPP 是环境转移，不由模型参数控制，所以梯度为 000；
  • 只有策略 πθ\pi_\thetaπθ​ 含有 θ\thetaθ。

因此：

∇θlog⁡pθ(τ)=∑t=1T∇θlog⁡πθ(at∣st).\nabla_\theta\log p_\theta(\tau) =\sum_{t=1}^{T} \nabla_\theta\log\pi_\theta(a_t\mid s_t).∇θ​logpθ​(τ)=t=1∑T​∇θ​logπθ​(at​∣st​).

代回目标函数，得到策略梯度：

∇θJ(θ)=Eτ∼pθ[R(τ)∑t=1T∇θlog⁡πθ(at∣st)]\boxed{ \nabla_\theta J(\theta) =\mathbb E_{\tau\sim p_\theta} \left[ R(\tau) \sum_{t=1}^{T} \nabla_\theta\log\pi_\theta(a_t\mid s_t) \right] }∇θ​J(θ)=Eτ∼pθ​​[R(τ)t=1∑T​∇θ​logπθ​(at​∣st​)]​

如果采样 NNN 条 rollout，期望可近似为样本平均：

∇θJ(θ)≈1N∑i=1NR(τ(i))∑t=1Ti∇θlog⁡πθ(at(i)∣st(i)).\nabla_\theta J(\theta) \approx \frac{1}{N}\sum_{i=1}^{N} R(\tau^{(i)}) \sum_{t=1}^{T_i} \nabla_\theta\log\pi_\theta (a_t^{(i)}\mid s_t^{(i)}).∇θ​J(θ)≈N1​i=1∑N​R(τ(i))t=1∑Ti​​∇θ​logπθ​(at(i)​∣st(i)​).

完整逻辑链现在是：

最大化期望回报
→ 把期望展开成轨迹概率加权和
→ 用 ∇log p = (1/p)∇p 把梯度改写成可采样的期望
→ 把整条轨迹的 log 概率拆成逐 token log 概率之和
→ 用 reward 加权每个已采样 token 的 log-prob 梯度

2.2 一条 rollout 如何变成可训练的 loss

2.1 得到的是一个期望：

∇θJ(θ)=E[R(τ)∑t∇θlog⁡πθ(at∣st)].\nabla_\theta J(\theta) =\mathbb E\left[ R(\tau)\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t) \right].∇θ​J(θ)=E[R(τ)t∑​∇θ​logπθ​(at​∣st​)].

训练时不可能枚举所有回答，只能让模型采样一批 rollout，用样本平均近似这个期望。对第 iii 条 rollout，我们已经保存了每个位置实际生成 token 的 logp，现在还缺一个问题：第 ttt 个 token 应该由哪些奖励负责？

动作 ata_tat​ 只能影响它发生之后的结果，不能影响过去已经拿到的奖励。因此给它使用从时刻 ttt 开始的累计回报。

这个量叫 reward-to-go，记作 GtG_tGt​：大写 GGG 是回报的惯用记号， 下标 ttt 表示从第 ttt 步开始计算；它不是一个新的 reward model。 定义为：

Gt=rt+γrt+1+γ2rt+2+⋯=∑k=tTγk−trk.G_t =r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots =\sum_{k=t}^{T}\gamma^{k-t}r_k.Gt​=rt​+γrt+1​+γ2rt+2​+⋯=k=t∑T​γk−trk​.

它执行的不是复杂算法，只是一条因果规则：

第 t 个 token 的训练权重
= 当前奖励 + 折扣后的未来奖励

如果奖励只在回答结束时给出，那么同一条回答中的各个 GtG_tGt​ 都由终点 reward 传播而来；若中间还有过程奖励或格式奖励，不同位置的 GtG_tGt​ 就会不同。

用 NNN 条 rollout 近似期望，并把梯度上升改写成深度学习框架使用的梯度下降，得到一个可最小化的 loss。

现在才给它命名：L\mathcal LL 表示 loss，下标 REINFORCE 表示这是刚才推导出的 REINFORCE loss；NNN 是本批 rollout 数量。因此：

2.4 回到乘法题：原始 REINFORCE 学到了什么

假设模型目前只会生成两种答案：

回答 当前概率 verifier reward
A：391 0.300.300.30 111
B：381 0.700.700.70 000

期望回报是：

如果本批采到 A，终点 reward 为 111，这条回答中的采样 token 获得正权重，A 的概率会上升。如果采到 B，reward 为 000，权重也是 000，这一条样本不更新策略。

反复采样后，A 一旦出现就会被增强，因此正确率仍然能够从 0.300.300.30 往上走。这说明 REINFORCE 已经解决了最基本的问题：即使正确答案不是监督标签，只要模型偶尔采到并获得奖励，也能提高它再次出现的概率。

但这个例子也暴露出两个结构性缺陷：

  1. 零分不是负反馈。 B 得到 000 时只是没有更新，不会被直接压低；
  2. 绝对分数没有参照系。 同样得到 111 分，可能是简单题上的正常发挥，也可能是难题上的罕见成功，却会得到相同权重。

如果奖励只在终点出现，整条回答中的 token 还会共享非常相似的回报信号，credit assignment 也很粗。原始 REINFORCE 因而“能学”，但样本效率和稳定性都不理想。

2.5 REINFORCE 与 SFT 的差别

两者的代码表面都包含 -weight * logprob，但数据来源与优化含义不同：

SFT 原始 REINFORCE
token 来自人类或离线参考答案 token 来自当前模型自己的 rollout
每个目标 token 通常都用正的 mask 权重 权重来自实际观察到的 reward-to-go
目标是复现给定答案 目标是改变采样分布、提高期望 reward
本轮数据不由当前模型生成 模型一更新，下一批 rollout 分布就会变化

因此 REINFORCE 不是“给 SFT 交叉熵乘一个 reward”这么简单。它的训练数据来自策略自身，reward 又带有很强的随机性；后续方法都在处理由此产生的方差、信用分配和数据过期问题。

采样 rollout
→ 观察每一步之后的 reward-to-go G_t
→ 用 G_t 加权采样 token 的 log-prob

在当前题目和回答前缀下，这次结果比模型的正常表现好多少？

第三章：从“整份答案得几分”到“这一步比预期好多少”

第二章已经得到一个能训练的动作规则：

某一步之后得到的回报高，就提高当时采样 token 的概率；回报低，就降低它的概率。

本章开头暂时不再给这条规则起新的公式名。真正需要解决的问题是：第二章使用的 GtG_tGt​（从第 ttt 步开始实际得到的后续回报）同时混入了两类信息：

  1. 这道题本来有多难；
  2. 当前这个 token 选得是否比通常更好。

策略更新真正需要的是第二类信息。本章只解决这一件事。路线是：

先构造“正常水平”作为参照 → 再学习这个参照 → 再用相邻前缀之间的预测变化分配信用 → 最后才给已经理解的做法加上课本术语。

3.1 为什么绝对回报不是理想的更新权重

3.3 最自然的参照：站在当前前缀上，平均能得多少分

3.7 GAE：把不同视野的 TD 信息做指数加权

我们已经有每一步的预测修正 δt\delta_tδt​。可以把未来若干步的修正累加。下面 A^t(1)\widehat A_t^{(1)}At(1)​、A^t(2)\widehat A_t^{(2)}At(2)​ 和 A^t(3)\widehat A_t^{(3)}At(3)​ 的上标表示分别累计 1、2、3 个 TD 修正项：

A^t(1)=δt,\widehat A_t^{(1)}=\delta_t,At(1)​=δt​,
A^t(2)=δt+γδt+1,\widehat A_t^{(2)}=\delta_t+\gamma\delta_{t+1},At(2)​=δt​+γδt+1​,
A^t(3)=δt+γδt+1+γ2δt+2.\widehat A_t^{(3)}=\delta_t+\gamma\delta_{t+1} +\gamma^2\delta_{t+2}.At(3)​=δt​+γδt+1​+γ2δt+2​.

希望近处权重大、远处逐渐衰减，就得到 GAE。 λ∈[0,1]\lambda\in[0,1]λ∈[0,1] 是人为选择的衰减系数；每向未来多走一步，权重就再乘一次 γλ\gamma\lambdaγλ。因此：

A^tGAE(γ,λ)=∑l=0T−t(γλ)lδt+l.\widehat A_t^{\text{GAE}(\gamma,\lambda)} = \sum_{l=0}^{T-t} (\gamma\lambda)^l\delta_{t+l}.AtGAE(γ,λ)​=l=0∑T−t​(γλ)lδt+l​.

实现时通常反向递推：

gae = 0.0
for t in reversed(range(T)):
    nonterminal = 1.0 - done[t]
    delta = reward[t] + gamma * value[t + 1] * nonterminal - value[t]
    gae = delta + gamma * lam * nonterminal * gae
    advantage[t] = gae

value_target = advantage + value[:-1]

λ\lambdaλ 控制“相信一步 critic”还是“更多相信真实后续”：

  • λ=0\lambda=0λ=0：退化为一步 TD，通常方差低、偏差高；
  • λ→1\lambda\to1λ→1：接近长视野回报，通常偏差低、方差高。

done 不是实现细节。终止后没有下一个真实状态，必须切断自举，否则会把下一条样本的 value 串进本条轨迹。

3.8 只有终局 reward 时，GAE 到底做了什么

数学推理常见：

rt=0(t<T),rT=R.r_t=0\quad(t<T),\qquad r_T=R.rt​=0(t<T),rT​=R.

这不意味着所有 token 天生拥有精确的过程监督。GAE 的局部差异来自 critic：

  • 某个前缀让成功概率预测上升，附近 δt\delta_tδt​ 为正；
  • 某个前缀暴露错误，让预测下降，附近 δt\delta_tδt​ 为负；
  • 终局 reward 再修正整条预测链。

所以必须说清边界：

  1. GAE 能把学到的前缀价值变化传播成 token 级权重；
  2. 它不会凭空知道哪一步逻辑是对的；
  3. critic 不准时，细粒度 credit assignment 也不准；
  4. 如果不训练 critic，而只把同一序列 reward 广播给所有 completion token，那仍是序列级监督。

第二周会介绍另一条路线：对同一 prompt 采样一组回答，用组内均值代替 learned value baseline。那是 GRPO/GR-REINFORCE 的出发点，不要提前与本章混为一谈。

4.1 三份模型先分清

4.3 为什么直接优化概率比会失控

DKL(πold(⋅∣s)  ∥  πθ(⋅∣s)).D_{\mathrm{KL}} \left( \pi_{\text{old}}(\cdot\mid s) \;\|\; \pi_\theta(\cdot\mid s) \right).DKL​(πold​(⋅∣s)∥πθ​(⋅∣s)).

它回答：“本轮 current 离 rollout 快照走了多远？”

DKL(πθ(⋅∣s)  ∥  πref(⋅∣s)).D_{\mathrm{KL}} \left( \pi_\theta(\cdot\mid s) \;\|\; \pi_{\text{ref}}(\cdot\mid s) \right).DKL​(πθ​(⋅∣s)∥πref​(⋅∣s)).

它回答：“训练后的模型离长期 reference 走了多远？”

KL 角色 典型用途
old ↔ current 优化稳定性 early stop、调小 epoch/学习率
current ↔ reference 行为锚定 奖励塑形或额外正则

不要只写“监控 KL”而不说明是哪两份策略。

TRPO 直接提出一个带 KL 约束的优化问题，在局部二阶近似下得到 natural-gradient 风格的方向。PPO 用一阶优化和 clipping/KL penalty 给出更容易实现的近似。对本周主线，只需记住：TRPO 更显式地约束分布距离，PPO 更工程化，但 clip 不是数学上的硬信赖域。

步骤一：冻结 rollout 快照

  • completion_mask

终局任务最简单的版本：

下面公式中的三个 L\mathcal LL 分别表示 actor loss、value loss 和 KL loss； cvc_vcv​ 是 value loss 的系数，β\betaβ 是 KL loss 的系数。它们只负责调节三部分在总 loss 中的相对尺度：

for epoch in range(K):
    for mb in minibatches(rollout):
        new_logp = policy.logprob(mb.tokens)
        ratio = exp(new_logp - mb.old_logp)

        unclipped = ratio * mb.advantage
        clipped = clamp(ratio, 1-eps, 1+eps) * mb.advantage

        value_loss = masked_mean(
            (new_value - mb.value_target) ** 2,
            mb.mask,
        )

        loss = actor_loss + value_coef * value_loss
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
