WEEK BY WEEK

学习路线

01

策略梯度、Advantage 与 PPO

把 prompt + 已生成 token 看作 state，把下一个 token 看作 action；理解 REINFORCE、value/baseline、PPO clipping 和 KL 约束。

中文教材：从策略梯度到 PPO ↗可选课件 · RL Basics ↗可选课件 · Policy Gradients ↗
02

RLHF、可验证奖励与 GRPO

从 Bradley-Terry 推导 reward model 与 DPO，再把 verifier、RLVR 和 GRPO 放进同一张方法地图。

中文教材：偏好、Verifier 与 GRPO ↗可选课件 · RLHF / DPO ↗可选课件 · RL for Reasoning ↗
03

动手训练：先跑通 format-copy

从 tensor 契约、parser、mask 与 log-prob 开始，逐步实现 GR-REINFORCE、GRPO、KL 和 smoke test。

中文教材：把 LLM RL 真正跑起来 ↗可选作业 · CS285 Homework 4 ↗官方 starter code ↗
04

math-hard、消融与 Agent RL

建立可信实验：统计不确定性、消融、reward hacking、成本分析，以及向业务 Agent 环境迁移。

中文教材：实验、诊断与 Agent RL ↗可选作业 · diagnostics ↗Berkeley · Advanced LLM Agents ↗
01

SFT

模仿高质量示范，是后训练的冷启动。

02

PPO

稳定的在线策略更新；通过 clipping 与 KL 约束偏移。

03

DPO

直接从偏好对学习，不需要在线 rollout。

04

GRPO

同题多次采样，按组内相对奖励更新，适合可验证推理。

AFTER WEEK 4

下一步：把 verifier 换成你的业务环境。

数学、JSON、代码单测与工具调用都可以成为可验证奖励任务。先定义状态、动作、奖励、投机方式与评估集，再开始训练。
