第一章：先把 LLM 后训练写成一个 MDP

对应：L4 第 5–15 页。

强化学习不是“有 reward 的监督学习”。关键差异是：当前动作会影响未来会看见什么状态，也会影响未来能拿到的 reward。

一个 MDP 写作：

M=(S,A,P,r,ρ0,γ)\mathcal M=(\mathcal S,\mathcal A, P, r, \rho_0, \gamma)M=(S,A,P,r,ρ0​,γ)
  • sts_tst​：时刻 ttt 的状态；
  • ata_tat​：策略在该状态选择的动作；
  • P(st+1∣st,at)P(s_{t+1}\mid s_t,a_t)P(st+1​∣st​,at​)：环境转移；
  • rt=r(st,at)r_t=r(s_t,a_t)rt​=r(st​,at​)：即时奖励；
  • ρ0\rho_0ρ0​：初始状态分布；
  • γ∈(0,1]\gamma\in(0,1]γ∈(0,1]：折扣系数。

1.1 语言模型版本的 MDP

对一个 prompt xxx 和生成序列 y1,…,yTy_1,\ldots,y_Ty1​,…,yT​：

通用 RL LLM 后训练中的含义
状态 sts_tst​ (x,y<t)(x,y_{<t})(x,y<t​)：prompt 加上已生成前缀
动作 ata_tat​ 下一个 token yty_tyt​
策略 πθ(at∣st)\pi_\theta(a_t\mid s_t)πθ​(at​∣st​) 模型的 next-token softmax 分布
转移 PPP 把 token 追加到前缀；通常近似确定性
轨迹 τ\tauτ 一整条回答 (x,y1:T)(x,y_{1:T})(x,y1:T​)
reward reward model 分数、规则 verifier、单测结果、格式奖励等

这张表是本周最重要的翻译。之后看到 value、advantage、PPO ratio，都先把它们代回“某个回答前缀上的下一个 token”。

一个容易忽略的点

环境转移对 LLM 通常不是难点：生成 a_t 之后，下一个状态就是把它拼到上下文里。但策略会改变训练数据本身：模型更新后，会采到不同的 token、不同的推理路径和不同长度的回答。这正是 RL 比监督微调难的根源。

1.2 轨迹分布与优化目标

一条轨迹的概率为：

pθ(τ)=ρ0(s1)∏t=1Tπθ(at∣st)P(st+1∣st,at).p_\theta(\tau)=\rho_0(s_1)\prod_{t=1}^{T}\pi_\theta(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t).pθ​(τ)=ρ0​(s1​)t=1∏T​πθ​(at​∣st​)P(st+1​∣st​,at​).

我们希望最大化期望累计回报：

J(θ)=Eτ∼pθ(τ)[R(τ)],R(τ)=∑t=1Tγt−1rt.J(\theta)=\mathbb E_{\tau\sim p_\theta(\tau)}[R(\tau)],\qquad R(\tau)=\sum_{t=1}^{T}\gamma^{t-1}r_t.J(θ)=Eτ∼pθ​(τ)​[R(τ)],R(τ)=t=1∑T​γt−1rt​.

对数学题 verifier，常见 RRR 是最终答案正确时的 111，否则 000。对 RLHF，RRR 往往来自 reward model。注意：即使奖励只在最后给出，每一个生成 token 都参与决定了该最终奖励。

为什么不是直接把 reward 当 label？

监督学习有固定 (x,y)(x,y)(x,y)；RL 的 yyy 来自当前 πθ\pi_\thetaπθ​。你真正要调整的是“采到这条回答的概率”，而不是把一个标量 reward 伪装成 token 标签。

第二章：REINFORCE —— 让高回报轨迹更可能出现

对应：L5 第 3–12 页。

2.1 关键技巧：log-derivative trick

我们不能直接对采样动作求导，但可以利用：

∇θpθ(τ)=pθ(τ)∇θlog⁡pθ(τ).\nabla_\theta p_\theta(\tau) =p_\theta(\tau)\nabla_\theta\log p_\theta(\tau).∇θ​pθ​(τ)=pθ​(τ)∇θ​logpθ​(τ).

因此：

∇θJ(θ)=Eτ∼pθ[R(τ)∇θlog⁡pθ(τ)]=Eτ∼pθ[R(τ)∑t∇θlog⁡πθ(at∣st)].\begin{aligned} \nabla_\theta J(\theta) &=\mathbb E_{\tau\sim p_\theta} \left[R(\tau)\nabla_\theta\log p_\theta(\tau)\right]\\ &=\mathbb E_{\tau\sim p_\theta} \left[R(\tau)\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\right]. \end{aligned}∇θ​J(θ)​=Eτ∼pθ​​[R(τ)∇θ​logpθ​(τ)]=Eτ∼pθ​​[R(τ)t∑​∇θ​logπθ​(at​∣st​)].​

第二行成立的原因是：初始状态分布和环境转移不含 θ\thetaθ，求导后只剩策略项。这正是 L5 第 5–6 页红线划掉环境项的含义。

2.2 把公式翻成工程语言

对一次 rollout：

若整条回答 reward 高：
    增大这条回答中每个已采样 token 的 log probability
若整条回答 reward 低：
    降低这些 token 的 log probability

对应的最小损失可写作：

LREINFORCE=−1N∑i=1N∑tGt(i)log⁡πθ(at(i)∣st(i)),\mathcal L_{\text{REINFORCE}} =-\frac{1}{N}\sum_{i=1}^{N}\sum_t G_t^{(i)} \log\pi_\theta(a_t^{(i)}\mid s_t^{(i)}),LREINFORCE​=−N1​i=1∑N​t∑​Gt(i)​logπθ​(at(i)​∣st(i)​),

其中 Gt=∑k=tTγk−trkG_t=\sum_{k=t}^{T}\gamma^{k-t}r_kGt​=∑k=tT​γk−trk​ 是 reward-to-go。

reward-to-go 为什么比整条回报更合理？

在时刻 ttt，动作 ata_tat​ 不可能影响它发生前的 reward。因此用完整 R(τ)R(\tau)R(τ) 给它打分，会把过去的随机性错误归因给当前动作。reward-to-go 只保留未来可受影响的部分，估计仍无偏，但噪声更低。这是 L5 第 18 页的“causality”。

2.3 REINFORCE 与 SFT 的差别

两者的代码表面都像 -weight * logprob，但语义不同：

SFT REINFORCE
token 来自人类/离线数据 token 来自当前模型 rollout
权重通常为正的 token mask 权重是可正可负的 return/advantage
目标：复现参考答案 目标：改变采样分布以提高期望 reward
数据分布不随当前模型改变 模型一更新，下一批数据分布就变

所以不能把 RL loss 当作“带一个 reward 权重的交叉熵”就结束；后面所有稳定化机制都在处理这个分布耦合问题。

第三章：从回报到 Advantage —— 解决 credit assignment 与高方差

对应：L5 第 14–18 页、L6 第 3–25 页。

3.1 为什么 raw return 不够用

考虑两条回答都答对，最终 reward 都为 1：

  • 第一条是模型在简单题上本来就会的；
  • 第二条是在很难的题上偶然推对了。

如果都乘 1，更新会把第一条中本就高概率的普通 token 也强力推高。真正有用的问题是：这个动作比模型在这个状态下的正常水平好多少？

定义：

Vπ(s)=Eπ[Gt∣st=s],Qπ(s,a)=Eπ[Gt∣st=s,at=a],V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s],\qquad Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a],Vπ(s)=Eπ​[Gt​∣st​=s],Qπ(s,a)=Eπ​[Gt​∣st​=s,at​=a],
Aπ(s,a)=Qπ(s,a)−Vπ(s).A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).Aπ(s,a)=Qπ(s,a)−Vπ(s).
  • VVV：看到该前缀时，模型平均还能拿多少分；
  • QQQ：此刻选定某 token 后，平均还能拿多少分；
  • AAA：这个 token 是否超出该前缀下的“正常发挥”。

3.2 baseline 为什么不改变正确答案

对任意只依赖状态、而不依赖当前动作的 b(st)b(s_t)b(st​)：

Eat∼πθ[b(st)∇θlog⁡πθ(at∣st)]=0.\mathbb E_{a_t\sim\pi_\theta} [b(s_t)\nabla_\theta\log\pi_\theta(a_t\mid s_t)]=0.Eat​∼πθ​​[b(st​)∇θ​logπθ​(at​∣st​)]=0.

因此可以把 GtG_tGt​ 换成 Gt−b(st)G_t-b(s_t)Gt​−b(st​)，期望梯度不变。取 b=Vϕb=V_\phib=Vϕ​ 后就是 advantage。直觉上，baseline 只是“同一状态的平均线”：超过平均线才鼓励，低于平均线才抑制。

3.3 actor 与 critic 各做什么

  • Actor：πθ\pi_\thetaπθ​，决定下一个 token；
  • Critic：VϕV_\phiVϕ​，预测当前前缀的预期回报；
  • Actor loss：用 A^t\hat A_tA^t​ 加权更新 token 概率；
  • Critic loss：拟合回报，例如 ∥Vϕ(st)−Gt∥2\|V_\phi(s_t)-G_t\|^2∥Vϕ​(st​)−Gt​∥2。

critic 不是 reward model。reward model / verifier 定义“什么算好”；critic 只是学习预测“当前策略在这个状态大概会拿几分”，服务于低方差更新。

3.4 TD、n-step 与 GAE

只等到整条回答结束再算 GtG_tGt​ 是 Monte Carlo：无偏但方差高。只看一步 TD residual：

δt=rt+γVϕ(st+1)−Vϕ(st)\delta_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)δt​=rt​+γVϕ​(st+1​)−Vϕ​(st​)

方差低，但 critic 不准会引入偏差。

GAE 用 λ\lambdaλ 在两者之间插值：

A^tGAE(γ,λ)=∑l=0T−t−1(γλ)lδt+l.\hat A_t^{\text{GAE}(\gamma,\lambda)} =\sum_{l=0}^{T-t-1}(\gamma\lambda)^l\delta_{t+l}.A^tGAE(γ,λ)​=l=0∑T−t−1​(γλ)lδt+l​.
  • λ→1\lambda\to1λ→1：更接近 Monte Carlo，偏差小、方差大；
  • λ→0\lambda\to0λ→0：更接近一步 TD，方差小、但更依赖 critic；
  • 实践中常从 γ≈1\gamma\approx1γ≈1、λ∈[0.9,0.97]\lambda\in[0.9,0.97]λ∈[0.9,0.97] 开始，而不是把它们当神奇常数。

L6 第 24 页的图表达的正是：把不同 n-step return 按指数衰减权重混合，而不是硬选一个 n。

3.5 LLM 场景的 advantage

若只有最终 verifier reward，token 级 advantage 会非常稀疏。常见选择：

  1. PPO/RLHF：训练 value head，以 GAE 得到 token 级 A^t\hat A_tA^t​；
  2. GRPO：对同一 prompt 采样一组回答，用组内相对 reward 构造基线，避免单独训练 value model；
  3. 结果奖励之外加可控的过程/格式奖励，但必须警惕模型投机 reward。

第四章：为什么要 PPO —— 同一批 rollout 不能随便多训

对应：L9 全部、L10 第 6–22 页。

4.1 on-policy 的限制

REINFORCE / on-policy actor-critic 假设样本来自当前策略 πθold\pi_{\theta_{old}}πθold​​。一旦连续更新多步，当前策略变成 πθ\pi_\thetaπθ​，它与采样策略不同；直接把旧样本当新样本优化，会产生 distribution mismatch。

重要性采样给出修正比率：

rt(θ)=πθ(at∣st)πθold(at∣st)=exp⁡(log⁡πθ−log⁡πθold).r_t(\theta)= \frac{\pi_\theta(a_t\mid s_t)} {\pi_{\theta_{old}}(a_t\mid s_t)} =\exp(\log\pi_\theta-\log\pi_{\theta_{old}}).rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​=exp(logπθ​−logπθold​​).

对应 surrogate objective：

LIS(θ)=Et[rt(θ)A^t].L^{\text{IS}}(\theta)= \mathbb E_t[r_t(\theta)\hat A_t].LIS(θ)=Et​[rt​(θ)A^t​].

它允许旧 rollout 在新策略下仍被利用，但有一个致命问题：当 ratio 离 1 很远时，估计方差会爆炸，少数 token 会主导更新。

4.2 PPO clip 的精确含义

PPO 的常用目标是：

Lclip(θ)=Et[min⁡(rtA^t,clip⁡(rt,1−ϵ,1+ϵ)A^t)].L^{\text{clip}}(\theta)= \mathbb E_t\left[ \min\left(r_t\hat A_t, \operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\right) \right].Lclip(θ)=Et​[min(rt​A^t​,clip(rt​,1−ϵ,1+ϵ)A^t​)].

它不是“把 ratio 直接截断然后照常最大化”这么简单；外层的 min 使它成为一个保守目标：

  • A^t>0\hat A_t>0A^t​>0 时，如果新策略已经把这个好 token 的概率提高超过 1+ϵ1+\epsilon1+ϵ，继续提高不再获得额外收益；
  • A^t<0\hat A_t<0A^t​<0 时，如果新策略已把这个坏 token 的概率压低超过 1−ϵ1-\epsilon1−ϵ，继续压低也不再获得额外收益。

因此 PPO 是在说：这批数据只允许你在旧策略附近改进一点。

4.3 KL 为什么仍然必须监控

clip 约束的是单个 token 的 ratio，不能严格保证整体策略分布距离小。L10 进一步从 trust region 出发，限制：

Es∼dπold[DKL(πold(⋅∣s)∥πθ(⋅∣s))]≤δ.\mathbb E_{s\sim d_{\pi_{old}}} [D_{\mathrm{KL}}(\pi_{old}(\cdot\mid s)\|\pi_\theta(\cdot\mid s))] \le \delta.Es∼dπold​​​[DKL​(πold​(⋅∣s)∥πθ​(⋅∣s))]≤δ.

实践中常见总损失可以写成：

L=−Lclip+cvLvalue−ceH(π)+β KL(πθ∥πref).\mathcal L= -L^{\text{clip}} +c_v\mathcal L_{value} -c_e\mathcal H(\pi) +\beta\,\mathrm{KL}(\pi_\theta\|\pi_{ref}).L=−Lclip+cv​Lvalue​−ce​H(π)+βKL(πθ​∥πref​).
  • value loss：让 critic 可用；
  • entropy bonus：避免过早变得确定；
  • KL to reference：不让已训练好的语言能力因奖励优化而漂移过远。

在 LLM RL 中，old policy 与 reference policy 不是同一个概念：前者用于这一个 PPO batch 的 importance ratio；后者通常是 SFT 模型，用于长期行为锚定。

4.4 TRPO 与 natural gradient 要记住什么

L10 后半段给出更理论化的视角：普通梯度以参数欧氏距离衡量步长，但神经网络参数的“小变化”不一定代表策略分布变化小。Fisher information 定义的 natural gradient 更关心输出分布的实际变化。

你不需要本周实现 TRPO，但应理解它和 PPO 的共同核心：限制策略函数空间中的改变量，而不是迷信参数空间中的学习率。

第五章：把整条链放回 LLM RL 训练循环

下面是本周应能读懂的概念伪代码：

# old_policy 用来采样和计算 ratio；reference_policy 用来施加长期 KL 锚定
rollouts = sample(old_policy, prompts, temperature=...)
rewards = verifier_or_reward_model(prompts, rollouts)

# PPO: value head + GAE；GRPO: 同 prompt 的 group-relative reward
advantages, returns = estimate_advantage(rollouts, rewards, value_model)

for epoch in range(num_epochs):
    logp = policy.logprob(rollouts.tokens)
    ratio = exp(logp - rollouts.old_logp)
    policy_loss = -mean(min(ratio * advantages,
                            clip(ratio, 1-eps, 1+eps) * advantages))
    value_loss = mse(value_model(rollouts.states), returns)
    kl_loss = mean(logp - reference_policy.logprob(rollouts.tokens))
    loss = policy_loss + c_v * value_loss + beta * kl_loss
    loss.backward(); optimizer.step()

训练日志至少同时看：

指标 你在问什么
verifier/reward 均值 模型是否真的在任务上变好？
KL to reference 是否以牺牲原有分布换 reward？
clip fraction / ratio 分布 单次更新是否过大？
advantage 均值与标准差 归一化、reward 标度是否异常？
value loss / explained variance critic 是在帮助还是在制造偏差？
response length、格式通过率、样例 是否出现 reward hacking？

第六章：本周的三个常见误解

误解 1：PPO 就是“带 clip 的交叉熵”

不对。PPO 的本质是旧策略采样下的 surrogate policy improvement；clip 是为了控制复用旧 rollout 时的策略漂移。没有 old_logp、advantage 和 rollout 分布，只有一个 clipped cross-entropy 并不等于 PPO。

误解 2：value model 就是 reward model

不对。reward model 评价一个回答的偏好或质量；value model 预测当前策略从一个前缀继续生成的期望回报。前者定义优化方向，后者主要降低估计方差。

误解 3：reward 上升就说明模型更强

不一定。模型可能学会输出更长、钻格式 verifier 空子、利用 reward model 的漏洞，或因为 KL 太弱而丢失通用能力。必须结合 held-out verifier、人工样例和 KL/长度曲线判断。
